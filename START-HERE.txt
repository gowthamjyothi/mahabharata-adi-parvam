ADI PARVA ARCHIVE — ఆది పర్వం
================================

WHAT IS IN THIS ZIP
  src/      All source code (React + TypeScript + Vite)
  dist/     Pre-built website (ready-made files)
  scripts/  Data validation and render checks
  README.md Full documentation (architecture, how to add characters)

RUN THE WEBSITE (needs Node.js 18 or newer)
  1. Open a terminal in this folder.
  2. npm install
  3. npm run dev
  4. Open the address it prints (usually http://localhost:5173)

VIEW THE ALREADY-BUILT VERSION
  npm install
  npm run preview

USEFUL COMMANDS
  npm run build       Rebuild into dist/
  npm run validate    Check that every family link and story cast resolves
  npm run typecheck   TypeScript check with no output files

WEBSITE — తెలుగు
  ఈ ఫోల్డర్‌లో టెర్మినల్ తెరవండి → npm install → npm run dev
  తర్వాత బ్రౌజర్‌లో చూపించిన చిరునామాను తెరవండి.
  ప్రతి పేజీ పైన ENGLISH / తెలుగు బటన్ ఉంటుంది.

NOTE
  The site uses client-side routes (/characters/bhima, /stories/...), so it
  must be served by a web server (npm run dev or npm run preview), not opened
  by double-clicking dist/index.html.
